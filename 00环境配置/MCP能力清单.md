# MCP 能力清单

> 本清单只登记可使用的外部能力、权限边界与降级方式，不记录地址、账号、令牌、密钥、客户数据或完整请求日志。共同规则见《AI能力治理规范》。

## 使用规则

1. 调用前确认当前工具已接入对应能力，且用户已授权目标空间或项目。
2. R 级只读操作限于用户说明的范围；W 级写入须先确认目标、范围和数量；D 级删除、归档、覆盖须列精确目标并二次确认。
3. 外部写入完成后，回写本地规划或变更记录；连接不可用时只输出待执行清单，不得声称已执行。
4. 实际配置和运行日志均为本地敏感资产，不得提交 Git。
