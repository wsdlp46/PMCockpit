# 智慧园区巡检 V0.1.0｜巡检任务列表 PRD

## 1. 背景与目标

物业主管需要集中查看当天巡检任务并跟进完成情况。本版本目标是降低遗漏风险，不处理任务配置或日报导出。

## 2. 用户与权限

物业主管可以查看当天任务、按状态筛选任务、将待巡检任务标记为已完成。巡检人员和系统管理员不在本页面的首版范围内。

## 3. 功能需求

### 3.1 查看今日任务

页面默认展示当天的巡检任务。每条任务显示任务名称、巡检区域、计划完成时间、负责人和状态。

### 3.2 按状态筛选

主管可选择“全部”“待巡检”或“已完成”。筛选后仅展示匹配任务，并显示匹配数量。

### 3.3 标记完成

仅“待巡检”任务显示“标记完成”按钮。主管确认后，任务状态变为“已完成”，按钮不再显示。

## 4. 业务规则

1. 默认日期为当天；本版本不支持切换日期。
2. 标记完成后不可在本页面撤销。
3. 无匹配任务时显示空状态，不显示错误信息。

## 5. 非本期范围

任务创建、任务编辑、巡检规则配置、日报导出、移动端操作。
