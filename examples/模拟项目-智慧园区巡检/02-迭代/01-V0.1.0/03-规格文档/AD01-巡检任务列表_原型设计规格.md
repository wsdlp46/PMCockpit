# AD01｜巡检任务列表｜原型设计规格

> 关联需求：`智慧园区巡检_V0.1.0_PRD.md` 第 3 章。

## 1. 页面定位

管理后台页面，面向物业主管。用于查看当天巡检任务、按状态筛选，并将待巡检任务标记为已完成。

## 2. 页面模块

### 2.1 页面标题与说明

- 标题：今日巡检任务。
- 辅助说明：展示当天需处理的巡检事项。

### 2.2 状态筛选

- 选项：全部、待巡检、已完成。
- 默认：全部。
- 操作结果：列表仅保留匹配状态的任务，任务数量同步更新。

### 2.3 任务列表

| 字段 | 说明 |
|---|---|
| 任务名称 | 巡检事项名称。 |
| 巡检区域 | 本次巡检对应的园区区域。 |
| 计划完成时间 | 当天计划完成的时间。 |
| 负责人 | 负责执行任务的巡检人员。 |
| 状态 | 待巡检或已完成。 |
| 操作 | 仅待巡检状态显示“标记完成”。 |

### 2.4 标记完成

点击“标记完成”后弹出确认提示。确认后，该行状态变为“已完成”，操作列显示“—”，任务数量不变。

## 3. 状态与异常

- 无匹配任务：列表区显示“暂无符合条件的巡检任务”。
- 本页只演示前端状态切换，不写入外部系统。
