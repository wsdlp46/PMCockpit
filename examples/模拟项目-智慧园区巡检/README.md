# 智慧园区巡检｜十分钟演练

> 这是仅用于学习 PMCockpit 流程的模拟项目，不含真实客户、人员或业务数据。正式工作请新建自己的项目，不要直接在本目录中产出。

## 演练目标

完成一次最小闭环：理解原始需求，检查 PRD 与规格的对应关系，修改一个原型文案，并构建出单文件 HTML。

## 第一步：复制练习项目

在 PMCockpit 根目录执行：

```bash
cp -R "examples/模拟项目-智慧园区巡检" "02当前项目/智慧园区巡检-练习"
```

后续所有修改只发生在 `02当前项目/智慧园区巡检-练习/`，样例目录保持原样，方便下次重新演练。

## 第二步：理解输入与产物

依次阅读：

1. `02-迭代/01-V0.1.0/01-原始需求/模拟需求.md`
2. `02-迭代/01-V0.1.0/02-需求文档/智慧园区巡检_V0.1.0_PRD.md`
3. `02-迭代/01-V0.1.0/03-规格文档/AD01-巡检任务列表_原型设计规格.md`

然后对 AI 说：

```text
请核对这三份文件：原始需求、PRD 和页面规格是否一致。只列出发现的问题和依据，不修改文件。
```

预期：AI 能指出“原始需求提出什么、PRD 定义什么规则、规格如何落到页面字段和操作”，而不会把未确认内容当作既定事实。

## 第三步：修改原型

对 AI 说：

```text
根据 AD01-巡检任务列表_原型设计规格.md，将原型页标题由“巡检任务”改为“今日巡检任务”，并同步右侧说明中的同一处文案。只修改 04-原型/ 中的 .src.html 源文件。
```

预期：AI 只修改 `AD01-巡检任务列表.src.html`，不直接改构建产物。

## 第四步：构建验证

执行：

```bash
bash "02当前项目/智慧园区巡检-练习/02-迭代/01-V0.1.0/04-原型/_scaffold/build.sh"
```

预期：同目录生成 `AD01-巡检任务列表.html`，输出中没有错误；打开该文件可以看到任务列表和右侧说明。

## 完成标准

- 能说明原始需求、PRD、页面规格和原型各自解决什么问题。
- 能区分 `.src.html` 源文件与构建后的 `.html` 交付文件。
- 修改源文件并成功重新构建。
- 知道真实项目应先说“新建项目”，项目建立后才说“开始新版本”。
