## 使用场景

| 场景 | 取用什么 |
|------|----------|
| 新项目启动 | 关键决策模板、会议纪要时间线模板 |
| 画原型 | prototype-html-pin 视觉基线（`assets/design/`）→ 设计规范（组件参数）→ 方法论 |
| UI走查/评审 | 设计检查清单 |
| 写文档遇到术语 | 术语表 |
| 项目上线排期 | 模板 → 系统上线项目管理模板 |
| 查设计约定 | 设计库 → 设计约定.md |
| 查历史案例 | 03知识库/工作案例库/ |
| 使用 MCP、连接器或跨工具 Skill | AI能力治理规范 → `00环境配置/MCP能力清单.md` → `.ai/TOOL-MAPPING.md` |
| 搭建/维护文档站 | 仅已有独立站点且显式启用后，使用可选 vitepress-deploy（`.ai/optional-skills/vitepress-deploy/`）；未启用时不集成该能力 |
