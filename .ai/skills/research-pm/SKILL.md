# research-pm 调研工作流 Skill

## 触发条件

用户要求"调研、市场调研、客户分析、行业研究、政策研究、搜集信息出报告、调研竞品、对比厂商、选型依据、竞品分析报告、这个功能别人怎么做的"时触发。本 skill 是调研类任务的唯一入口，按场景路由到类型卡。

## 场景路由（进入后第一件事）

| 用户诉求 | 路由 | 说明 |
|---------|------|------|
| 研究对象是"我们与对手的优劣"（对比厂商、选型依据、竞品报告、这个功能别人怎么做） | [types/类型卡-竞品分析.md](types/类型卡-竞品分析.md) | 按卡的竞品六阶段流程执行（竞品分层、覆盖度校验、差异化判定为卡内专属），阶段三信息组织与阶段六闭环沿用本主流程 |
| 研究对象是"客户与市场"（客户分析、画像、方案包、报价） | [types/类型卡-客户分析.md](types/类型卡-客户分析.md) | 含阶段零加问、采集侧重、业务分析五小节、报告骨架 |
| 其他调研类型（行业研究、政策研究、收费模式等） | 走本主流程六阶段，暂不用卡 | 新类型出现两次真实需求后再建卡（见 types/说明.md） |

## 六个工作阶段 + 闭环（两闸门）

```
闸门①：边界未确认，不动手
  ↓
阶段零 边界确认 → 阶段一 拆解分工 → 阶段二 采集执行 → 阶段三 信息组织 → 阶段四 洞见提炼 → 阶段五 分层产出
                                                                              ↓
                                                              闸门②：确认内容与表达形式后才归档闭环
```

| 阶段 | 做什么 | 关键规则 |
|------|--------|---------|
| 零 边界确认 | 先从用户输入和项目资料提取已知项，再一次确认缺项：调研主题、客户/场景假设（最关键）、报告用途、决策定位；同时落口径（计价币种、汇率、价格基准、数据来源与总预算） | 缺关键项不采集；使用当前运行环境提供的提问能力一次问清，避免重复追问 |
| 一 拆解分工 | 将研究问题按需拆为 A 认知型（要判断）、B 数据型（结构化采集）、C 操作型（登录态/真机） | 小任务由主 Agent 直接完成；仅将可独立验证的任务交给子 Agent。B 类先行，A 类与其错峰并行 |
| 二 采集执行 | 按调度红线执行主 Agent 或子 Agent 采集 | 见下节 |
| 三 信息组织 | 底稿制度：每子任务落底稿（raw + 整理稿），统一可信度五级，缺口显式列待补 | 结论必须可溯源到底稿与采集日期 |
| 四 洞见提炼 | 五个透镜过底稿：测算、核正、结构、反例、差异化 | 每条洞见标注用哪个法、挂哪份底稿 |
| 五 分层产出 | 完整版（论证）+ 汇报稿（决策），**默认全部 MD 草稿**；非 MD 表达形式须待用户确认内容后再转换 | 表达形式确认前不锁定，避免过早做 HTML、PDF 或 PPT |
| 六 确认闭环 | 三清单出口：拍板清单（每条自解释）、待核清单（归上游对接）、推迟需求（进需求池）+ 复盘 | 闸门②：经用户确认后归档定稿、更新索引并记录待办去向 |

> 竞品场景的阶段零至五按竞品卡流程执行，通用机制仍走本表。

## 调度红线（标注：初版经验值，来自单次任务，第二次任务须校准）

1. 联网型子 Agent 并行不超 2 个（在跑不超 2，其余排队）；限频失败先等在跑的结束再重试，不叠加并行
2. 单个子 Agent 检索上限：认知型 10-15 次、数据型 8-12 次；采不到的列"待补"，禁止硬搜
3. 长表数据（超 20 行）由子 Agent 直接写入项目底稿文件，最终消息只回路径 + 关键数字 + 异常，不超 600 字
4. 阶段零先约定总检索或费用预算，并为每项子任务分配份额；达到约定预算的 60% 时只补关键缺口，达到上限或预计超限时立即停止采集并汇报。运行环境无法显示用量时，完成第 2 个子任务后先复核缺口再决定是否继续派发
5. 单任务子 Agent 最多派 8 个；不因凑齐数量而派发。总消耗在复盘中记录并校准下次预算
6. 操作型（浏览器/真机）只读、工具调用设上限、用 evaluate/接口提取禁整页快照
7. 退出机制：阶段二结束缺口超四成，中止并汇报，不硬凑进入阶段四

## 汇报稿规范（MD 默认）

1. 完整版与汇报稿都先出 MD，结构按类型卡的报告骨架
2. 用户确认内容后指定表达形式才转换；某形式被用两次以上才沉淀模板
3. 行文三条（来自教训，随卡携带）：
   - 表格单元格、标题、清单条目脱离上下文要能读懂，禁压缩腔
   - 高频变动数字（竞品价格、套餐档位）不写死进正文，正文只写结构事实，数字入带采集日期的底稿
   - 未建成能力标注（规划中），不混入卖点
