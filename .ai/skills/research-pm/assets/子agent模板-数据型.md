# 子 Agent 模板：数据采集型（B 型）

用于价格、清单、覆盖核对等结构化数据采集。复制本模板，替换占位符后作为子 Agent 的 prompt。

## 模板

```
你是价格/数据采集子agent，为{项目/主体}采集{对象}。今天是{日期}。使用当前运行环境已授权的联网检索与页面读取能力完成，控制在8-12次检索内，一律以官方定价页为准，逐条标注来源URL和采集日期。注意控制请求节奏，避免触发速率限制。

已核实的锚点数据（可直接引用，无需重查）：{锚点1}；{锚点2}

采集清单（版本以当前官方主推为准，全部档位都要，不只最低档）：
{1-6 项，每项给模型/站点/关注点}

输出格式：中文Markdown表格，列：{环节/能力}、{对象}（含版本档位）、{厂商/来源}、计价单位、官方价格（全档位）、{订阅/免费额度/限流}、来源URL、采集日期、备注（标注直接抓取/搜索索引/第三方转述）。最后附"价格意外发现"小节（免费额度、新用户赠送、批量折扣阶梯、近期调价动向）。短表（20行以内）最终消息即报告本身；长表按下方长表规则写文件后只回摘要。
```

## 长表规则（本型核心差异点）

- 采集结果超过 20 行时，**先写入指定项目文件**（路径在 prompt 里给出，如 `{项目}/客户分析_调研底稿/{编号}_{主题}_{日期}.md`）
- 最终消息**不超 600 字**：只回 文件路径与写入状态、条目总数、字段结构说明、10 个代表样例、异常情况、重叠/缺口一句话
- 原文保留原始口径（如美元价），换算类处理在整理稿注明，不要在 raw 文件里换算

## 可信度标注

| 标注 | 含义 |
|------|------|
| 直接抓取 | 本次成功抓取官方页面 |
| 搜索索引 | 搜索引擎对官方页面的索引摘要 |
| 第三方转述 | 非官方来源，仅供参考 |
| 待补 | 抓取失败（JS 渲染/404/超时），列待补清单并注明原因 |
| 锚点沿用 | 引用已有底稿已验证数据，标注未复核 |

## 已知边界

- 动态页/JS 渲染页抓不到：列待补，不硬试（可注明"需浏览器人工复核"）
- 被限频时停下等待，不要立刻重试
