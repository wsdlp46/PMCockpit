## 五、执行计划与通过标准

| 轮次 | 范围 | 说明 |
|---|---|---|
| 轮0 结构核验 | 【只读用例集】 | 不动数据，验证页面结构与规格一致 |
| 冒烟轮 | 【P0 主链路用例编号列举】 | 打通主流程，冒烟不过不进入全量 |
| 全量轮 | 全部 N 条 | 【是否人工与 Agent 并行】 |
| 回归轮 | 失败用例 + 受影响存量用例 | 缺陷修复验证，范围按缺陷影响面确定 |

**度量指标**：P0 通过率；缺陷数量与分级；Agent 与人工判定一致率（首轮核心指标）；全量执行耗时。

**通过标准**：【P0 全部通过；P1 遗留缺陷经产品确认风险可接受；无 [资金/数据] 正确性类的 P1 及以上缺陷遗留。】
