# Skill 资产登记表

> 仅登记允许进入发行版 Skill 的跨项目资产。项目业务材料、真实案例、凭证、客户截图和一次性产物不得写入 Skill 目录。

| Skill | 资产槽 | 准入边界 | 验证方式 |
|---|---|---|---|
| prototype-html-pin | `assets/design/`、`assets/scaffold/`、`assets/tokens/` | 脱敏、跨项目可复用的视觉基线和原型脚手架 | 用空白示例页构建并人工检查 |
| research-pm | `types/`、`assets/` | 不含真实项目、客户、报价和调研结论的流程类型卡与模板 | 用等价虚拟场景完成边界确认、采集和报告闭环 |
| test-flow-pm（可选） | `assets/` | 不含真实账号、截图或测试数据的方案、报告和子 Agent 模板 | 使用虚拟项目验证确认门、用例结构和报告归档 |

模板型 Skill 的资产演进仍遵循对应 Skill 的输入、确认门与验证要求，不因登记表缺少专用资产槽而绕过审查。
