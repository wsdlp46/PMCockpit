# 知识卡片模板

> 知识大脑只保存会影响业务判断的领域结论，不保存工作方法、检查清单、项目专属事实或未验证猜测。

```markdown
# KB-XXX 结论式标题

- 知识类型：行业认知 / 客户判断 / 政策口径 / 业务模式
- 状态：候选 / 有效 / 待复核 / 已过期
- 置信度：高 / 中 / 低
- 一句话结论：
- 适用边界：
- 反例与不适用场景：
- 证据数量：
- 最近核验日期：YYYY-MM-DD
- 有效截至：YYYY-MM-DD / 不适用
- 标签：

## 证据与来源

- [来源名称](相对路径)：说明其支持的判断与日期。

## 变更记录

| 日期 | 变更 | 原因 |
|------|------|------|
```

## 入卡标准

有效卡须同时满足：不少于两份相互独立的证据或不少于两个项目验证；会改变角色、范围、业务模式、政策口径、客户价值或其他业务判断；写清适用边界和至少一个反例；用户确认允许落盘。单一来源但有价值的结论只能建为候选卡。

政策、竞品和市场现状等易变化知识必须填写“最近核验日期”和“有效截至”；过期后只能作为历史证据，不得直接用于当前结论。
