# 标签体系

> 为案例库中所有案例统一打标，支撑跨领域检索和 AI 推荐。

| `停车-充电` | 充电桩业务 |
| `停车-交警` | 交警执法/追缴 |
| `数据-流通` | 数据共享/交换/交易 |
| `数据-治理` | 数据质量管理 |
| `数据-资产化` | 数据资产登记/估值/定价 |
| `数据-运营` | 数据资产运营 |
| `数据-空间` | 可信/城市数据空间 |
| `双碳-碳排放` | 碳排放数据 |
| `双碳-碳普惠` | 碳普惠/碳积分 |

## 使用方式

每个深度案例在"复用信号"区块填入对应的标签。例如：

```markdown
## 复用信号
| 维度 | 标签 |
|------|------|
| 适用行业 | `停车-路侧` `停车-商业场库` |
| 适用产品阶段 | `阶段-规模化` |
| 适用业务场景 | `客户-国企` `客户-政府` |
| 关键能力标签 | `能力-多租户` `能力-支付` `能力-硬件集成` |
| 文档类型参考 | `文档-PRD` |
```

索引级案例可在文件列表中直接用标签列标注。
