# 工作案例库

> 过往项目工作产物的分类索引与摘要。本仓库随框架分发的是建库框架（指南/模板/标签/方法论笔记），具体案例由你在真实项目结项后自行沉淀。

## 建库框架

- [[00-建库指南]] — 建库原则、使用方法、维护流程、知识闭环、Agent 架构
- [[案例模板]] — 深度案例的标准撰写模板
- [[标签体系]] — 跨领域检索的统一标签维度
- [[方法论_模式笔记]] — 从案例中提炼的跨项目通用模式
- [[方法论_错误笔记]] — 过往项目的踩坑记录和避免方法
- [[_index_AI匹配]] — 给 AI 用的领域到案例紧凑路由索引

## 领域分类约定

案例按领域建目录（如 `01-XX行业/`、`02-XX平台/`），每个领域目录内建 `_index.md` 子索引，深度案例按 [[案例模板]] 撰写。建库方法、三层结构与维护节奏见 [[00-建库指南]]。
