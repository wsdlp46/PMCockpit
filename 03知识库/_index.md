# 03知识库

> 跨项目沉淀的知识证据与案例。`01通用规则/` 保存方法和规则；本目录保存可核验的内容。框架初始不携带真实项目、客户或行业资料。

## 入口

- [[_index_AI匹配]] — AI 总路由，先判断是否需要知识卡、案例子路由或证据目录。
- [[知识大脑/卡片模板]] — 结论卡框架；使用者满足证据标准后自行建卡。
- [[工作案例库/_index]] — 案例库框架与方法论笔记。

## 证据目录

| 目录 | 内容 | 初始状态 |
|---|---|---|
| `工作案例库/` | 历史案例、模式和错误笔记 | 仅分发建库框架 |
| `政策法规/` | 政策、标准和法规原文/转换稿 | 空索引，使用者自行入库 |
| `竞品分析/` | 可核验的竞品调研报告与底稿 | 空索引，使用者自行入库 |
| `行业研究/` | 行业趋势、客户市场和研究报告 | 空索引，使用者自行入库 |
| `技术学习/` | 技术资料与可行性研究 | 保留已有通用学习笔记 |
| `读书笔记/` | 概念、方法和阅读笔记 | 空索引，使用者自行入库 |
| `知识大脑/` | 有证据、边界、反例和时效的结论卡 | 仅分发卡片模板 |

每个子目录新增、删除或更新资料后，必须同步维护其 `_index.md`；政策、竞品和市场类事实必须记录采集或核验日期。
