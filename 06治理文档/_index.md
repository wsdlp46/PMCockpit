# 治理文档

> 工作区级内部治理类文档：资产盘点、智能体审计、知识库巡检报告等。非业务产出、非经验总结，是工作区自身的"体检报告"和"账本"。

## 与其他目录的区分

| 目录 | 内容性质 | 读者 |
|------|---------|------|
| `05经验总结/01复盘总结/` | 过程改进教训（怎么做得更好） | 自己（下次怎么做） |
| `05经验总结/02项目总结/` | 项目成果固化（做成了什么） | 自己 + 团队 |
| `05经验总结/03经验输出/` | 对外传播文章 | 外部读者 |
| **`06治理文档/`（本目录）** | **工作区资产盘点、审计、巡检** | **自己（工作区健康度管理）** |

## 文档清单

| 文档 | 性质 |
|------|------|
| _待填充_（资产盘点类，重大资产变动后重新盘点） | 资产盘点：识别哪些资产可对外、需脱敏、不可对外 |
| _待填充_（审计类，按周期归档） | 智能体内容审计：检查工作区文档质量、过期内容 |
| _待填充_（巡检报告） | 结构合规、索引真实性、断链巡检 |

## 工具

- `scripts/check-workspace-links.mjs` — 全工作区内部链接检查（node 运行，自动跳过 .git / node_modules 等目录）

## 维护规则

- 盘点类文档按需更新，重大资产变动后重新盘点
- 审计类文档按周期归档，保留历史版本以便对比
- 巡检类报告（可由 `scripts/check-workspace-links.mjs` 等工具产出）产出时归入本目录
